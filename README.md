# Template-Easy-Setup-DevOps

## Dataview Script Blocks

- Set the scripts folder and block type in settings.
- Store `.js` scripts inside the vault folder you configured.
- If a script has no metadata header, its file name is used as the id.
- Use a code block to load a script by id:

```zettelkasten-query
research-literature-metadata-display
current: true
statisticOnly: false
```
